# Kalamata

Kalamata is a desktop app for downloading and managing Steam game files on
macOS and Windows. Look up a game by its Steam App ID, choose the depots
(file packages) you want, and install them to a folder of your choice.

## Features

- Install, update, repair, and uninstall game files.
- Choose platform and language depots, or pin a specific manifest version.
- Manage downloads with pause, resume, and cancel controls.
- Set up and manage ColdClient for installed games on Windows.
