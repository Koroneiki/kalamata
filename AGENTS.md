# AGENTS.md

## Project

Kalamata is a private Electrobun desktop application with a Vue/TypeScript frontend. Its Bun-based Steam depot downloader lives in `src/backend`, and the Electrobun process entrypoint is `src/bun/index.ts`.

## Commands

```sh
bun install
bun run dev
bun run build
bun test
bun run typecheck
```
